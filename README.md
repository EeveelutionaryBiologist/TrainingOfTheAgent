# Training of the Agent

In [The Binding of the Agent](https://github.com/EeveelutionaryBiologist/BindingOfTheAgent), a small coral blob descends
into ever-deeper codebases and dies to a Merge Conflict. This project asks the obvious follow-up question: can we teach
a neural network to die there instead of us?

The plan is a reinforcement learning agent that plays the game headless, at a few thousand times real time, on exactly
one home computer and whatever patience we have left. It gets the same information a human player sees on screen and nothing
more, so no peeking at disguised enemies or secret rooms. It also gets the same keys, minus the debug cheats.

Goal 0 is to survive one room against one Bug. Goal 1 is to beat the first floor once. Everything after that is
optimism.

This is an experiment, and it may well fail. If it does, we will at least know why, and the agent will have been
killed by a Flaky Test several million times, which is more than most of us can say.

Nothing is built yet. See [REQUIREMENTS.md](REQUIREMENTS.md) for what we intend to build.
